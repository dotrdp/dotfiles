* some recurrent task
  DEADLINE: <2025-08-29 Fri +1m -2d>
to make it recurrent you need to set the deadline or schedule then add a + recurrent ie.
  in this example we tell it to come back to us every month also if you want it to warn you a couple days before just add a -2d
  the -2d is so it tells you about it 2 days before

  *NOW THE IMPORTANT* , when you mark it as done with cit it will move the time forward and still markup as TODO, however it will keep track of when u marked it done

  if you add a ++ it will not add up multiple times every time you dont do it.

  if you add a .+ it will set the repeat date after you done it e.g
  for batteries you could set it to .+1m, once you change it it will set the next deadline to one month from the day you marked it as done
